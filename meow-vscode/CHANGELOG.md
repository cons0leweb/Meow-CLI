# Changelog

## [1.0.0] - 2026-04-19

### Added
- Full AI chat panel in VSCode sidebar with streaming responses
- Inline code actions: Explain, Refactor, Fix, Document, Generate Tests
- Autopilot mode with autonomous task execution
- Tool execution: read/write/patch files, shell, git, web search
- RAG memory integration with ~/.meowcli/data/memory/
- Session management: save, load, compact
- Permission system: allow/ask/deny per tool
- Checkpoint system: file backups before destructive operations
- Cost tracker: token usage and API cost estimation
- Status bar integration
- Sessions, Memory, and Tool Calls tree views
- Support for Anthropic, OpenAI, OpenRouter, and Ollama providers
- Full VSCode theme compatibility (dark/light/high contrast)
